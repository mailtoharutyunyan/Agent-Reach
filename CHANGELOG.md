# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-09-26

### ✨ Features

- Installer, doctor, and config tool that gives AI agents read/search access to Twitter/X, Reddit, Facebook, Instagram, YouTube, GitHub, Bilibili, Xiaohongshu (RedNote), LinkedIn, BOSS Zhipin, V2EX, Xueqiu, Xiaoyuzhou Podcast, RSS, web search, and any web page
- `weblens doctor` diagnostics with per-platform backend fallback chains
- `weblens install` one-shot installer and `weblens skill` agent-skill registration (Claude Code, OpenClaw, Cursor, and others)
- `weblens watch` / `check-update` for scheduled health and update checks
- Xiaoyuzhou podcast transcription via Groq Whisper
